## <u>Software</u>

**GC-YZ** <small>[\[code\]](https://github.com/ScholarSun/GC-YZ-LIN-V)</small>  
Model-based derivative-free solver with Powell-style geometry correction and complexity guarantees. Code for Chaudhry, Scheinberg, and Sun (2026).

**Cosine-Measure-Benchmarking** <small>[\[code\]](https://github.com/ScholarSun/Cosine-Measure-Benchmarking)</small>  
Implements and benchmarks cosine measure algorithms on generated sets with known cosine measures. Code for Hare and Sun (2026).
